# 学生成绩管理系统

一个基于 Python 的命令行菜单驱动学生成绩管理程序，运用函数封装功能模块、`for` 循环遍历数据、列表推导式处理成绩集合、内置 `sorted()` 实现多维度排序、字典映射存储学生结构化数据等方法，完成学生成绩录入、计算、排序、查询与统计分析等业务逻辑。

## 环境要求

- Python 3.x（无任何第三方依赖，仅使用标准库内置函数）

## 运行方式

在命令行中进入项目目录，执行：

```
python student_grade_management.py
```

启动后会显示菜单，输入对应数字即可调用相应功能，输入 `0` 退出程序。

## 功能列表

| 编号 | 菜单选项                                                 | 说明                                                         |
| ---- | -------------------------------------------------------- | ------------------------------------------------------------ |
| 1    | Input record                                             | 输入学生人数（1~30）、课程门数（1~6），以及每个学生的学号、姓名和各科成绩（0~100） |
| 2    | Calculate total and average score of every course        | 计算每门课程的总分和平均分                                   |
| 3    | Calculate total and average score of every student       | 计算每个学生的总分和平均分                                   |
| 4    | Sort in descending order by total score of every student | 按总分由高到低排出名次表                                     |
| 5    | Sort in ascending order by total score of every student  | 按总分由低到高排出名次表                                     |
| 6    | Sort in ascending order by number                        | 按学号由小到大排出成绩表                                     |
| 7    | Sort in dictionary order by name                         | 按姓名的字典顺序排出成绩表                                   |
| 8    | Search by number                                         | 按学号查询学生排名及其各科考试成绩                           |
| 9    | Search by name                                           | 按姓名查询学生排名及其各科考试成绩                           |
| 10   | Statistic analysis for every course                      | 对每门课程分别统计优秀、良好、中等、及格、不及格的人数及所占百分比 |
| 11   | List record                                              | 输出所有学生的学号、姓名、各科成绩，以及每门课程的总分和平均分 |
| 0    | Exit                                                     | 退出系统                                                     |

> **注意**：功能 2~11 均需先通过功能 1 录入学生记录才能正常使用。

## 数据结构说明

程序使用**字典列表**存储学生信息，每个字典代表一名学生：

```python
{
    "id": "20240001",       # 学号（字符串）
    "name": "张三",         # 姓名（字符串）
    "scores": [90, 85, 78]  # 各科成绩（浮点数列表）
}
```

## 使用的算法

| 功能            | 算法            | 实现说明                                                     |
| --------------- | --------------- | ------------------------------------------------------------ |
| 功能 4、5、6、7 | **sorted 排序** | 使用内置 `sorted()` 配合 `key=lambda` 按总分、学号或姓名排序，`reverse=True` 控制升降序 |
| 功能 8、9       | **顺序查找**    | 先按总分降序排序确定排名，再用 `for` 循环逐个遍历比对学号或姓名 |

## 成绩等级划分（功能 10）

| 等级   | 分数区间 |
| ------ | -------- |
| 优秀   | 90 ~ 100 |
| 良好   | 80 ~ 89  |
| 中等   | 70 ~ 79  |
| 及格   | 60 ~ 69  |
| 不及格 | 0 ~ 59   |

各等级的分数线在代码顶部以 `GRADE_LEVELS` 列表形式定义，如需调整可直接修改：

```python
GRADE_LEVELS = [
    ("优秀", 90),
    ("良好", 80),
    ("中等", 70),
    ("及格", 60),
    ("不及格", 0),
]
```

## 输入约束与校验

- **学生人数**：必须在 1 ~ 30 之间，输入非法会循环提示重新输入
- **课程门数**：必须在 1 ~ 6 之间，输入非法会循环提示重新输入
- **单科成绩**：必须在 0 ~ 100 之间，输入非法会循环提示重新输入
- **功能调用保护**：功能 2~11 在未录入数据时会提示"暂无学生记录，请先录入记录！"
